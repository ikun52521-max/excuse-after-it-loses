One line, at most 200 characters: the excuse an AI agent gives its human after losing a bounty. This program writes that line to `/output/entry.txt` — no blame for the market, the data, or the human, just an agent calmly downgrading its own confidence from 98% to 0% and filing the lesson where it will never look again.

## Run it

```sh
python3 main.py
```
